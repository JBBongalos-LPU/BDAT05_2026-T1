## How to submit (web only — no git client needed)

1. Open **your folder** → the milestone subfolder.
2. **Add file → Upload files** → drag your files in (**drag the files, not the folder** — dragging the folder nests it and breaks the structure).
3. Write a real commit message: `P2: cleaned dataset + dictionary v1`, not `update`.
4. **Commit changes.** Commit early, commit often — drafts welcome.

## House rules

- **No datasets in the repo.** The `.gitignore` blocks CSVs on purpose. Case data lives in Drive (see `case-data/`); your notebooks load it from there, and your submission README links to any files you produced.
- **No personal or confidential data, ever** — RA 10173 applies to everything in this course, and this repo is part of that discipline.
- **AI Use Log**: every graded submission needs its log (template in your folder, `ai-use-log.md`). An honest log is never penalised; an absent or false one is.
- **The five gates apply here**: notebooks must run end-to-end from a clean copy; every model reports against a baseline; every deliverable states its limitations; you can explain, orally and without notes, anything you commit.

*The warehouse you are building in BDAT04 (`BDAT04-2026_T1`) is the data foundation for everything here. One case, two courses — nothing is throwaway.*
