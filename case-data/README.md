# Case data — Kape Tayo Coffee

**The data does not live in this repository.** The `.gitignore` blocks CSVs on purpose — this is the same discipline you will meet in every company that takes RA 10173 seriously.

Download the Kape Tayo files here:

**https://drive.google.com/drive/folders/1Z8bcT8oyLXgakBUK0vC_OYw39g2KU2rn**

Seven files: sales transactions, customers, products, branches, employees, inventory movements, and a calendar. Load them in Colab from your own Drive copy. Your BDAT04 warehouse (repo `BDAT04-2026_T1`) is the modelled, documented version of this same data — from Week 3 onward, prefer building on it.

If a graded submission produces a cleaned dataset, share it as a **Drive link inside your submission README**, not as a committed file.
